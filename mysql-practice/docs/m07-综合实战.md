# m07 综合实战：苍穹外卖统计报表 SQL

> 先读：MySQL 官方文档 “WITH (Common Table Expressions)” 和 “Window Functions”（看示例即可），或者搜索“MySQL 8 窗口函数 入门”
> 练习：`exercises/m07_report/`　判题：`mvn test -Dtest='QueryExercisesTest#m07'`

苍穹外卖管理端的“数据统计”页面有四个图表：营业额统计、用户统计、订单统计、销量排名 Top10。
本章就是它们背后的 SQL，以及几个常见的分析需求。

## 题目

| 题 | 对应功能 | 考点 |
|---|---|---|
| q01 | 营业额统计 | 递归 CTE 生成日期序列 + LEFT JOIN，没有数据的日期补 0 |
| q02 | 用户统计 | 多个 CTE、窗口函数累计求和 SUM() OVER |
| q03 | 订单统计 | 条件计数、百分比计算、日期范围边界 |
| q04 | 销量排名 Top10 | GROUP BY + ORDER BY + LIMIT |
| q05 | 每个分类最贵的菜 | ROW_NUMBER() OVER (PARTITION BY ...) 分组取第一 |
| q06 | 复购用户 | 分组 + HAVING |
| q07 | 下单时段分布 | CASE + GROUP BY |
| q08 | 营业额环比 | LAG() 取上一行 |

## 速记

```sql
-- 递归 CTE：生成 2024-05-01 ~ 2024-05-07
WITH RECURSIVE dates AS (
    SELECT DATE '2024-05-01' AS d
    UNION ALL
    SELECT d + INTERVAL 1 DAY FROM dates WHERE d < '2024-05-07'
)
SELECT d FROM dates;

-- 窗口函数：不合并行，给每一行算一个“窗口”内的值
SUM(x)        OVER (ORDER BY d)                          -- 累计和
ROW_NUMBER()  OVER (PARTITION BY category_id ORDER BY price DESC)  -- 组内排名
LAG(x)        OVER (ORDER BY d)                          -- 上一行的值
```

## 思考：统计放在 SQL 里还是 Java 里？

- 苍穹外卖原版：Java 里循环每一天，每天查一次 SQL（简单直观，但查询次数多）
- 本章写法：一条 SQL 查出全部（效率高，但 SQL 复杂）
- 你在 learn-java ch09 写过的 `ReportService`：数据全部取到内存里用 Stream 统计

三种方式都要会。实际项目里数据量大时，统计一般交给数据库做。
