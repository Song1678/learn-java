## 查询题的判题规则

- **列的数量、顺序、列名都要和题目“返回列”一致**（列名不区分大小写），所以该起别名就起别名
- 数字按数值比较：`28`、`28.0`、`28.00` 都算对
- 题目要求排序的，行的顺序也要一致；“排序：不要求”的只比较内容
- 文件头部的“期望结果”就是正确答案的输出，可以先自己对照

## 速记

```sql
SELECT 列1, 列2 AS 别名
FROM 表
WHERE 条件            -- = <> > >= < <=、AND OR NOT、BETWEEN a AND b、IN (...)、LIKE '%x%'、IS NULL
ORDER BY 列1 DESC, 列2  -- 默认 ASC
LIMIT 偏移量, 条数;    -- 第 n 页：LIMIT (n-1)*size, size
```

## 常见坑

1. 字符串用**单引号** `'宫保鸡丁'`。
2. 判断 NULL 必须用 `IS NULL`，`= NULL` 永远查不到。
3. 不写 `ORDER BY` 时返回顺序是不确定的，别依赖它。
4. `AND` 优先级高于 `OR`，混用时加括号。
5. SQL 关键字不区分大小写，习惯上关键字大写、表名列名小写。
