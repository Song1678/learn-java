## SQL 的执行顺序（一定要记住）

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

由此可以推出很多规则：
- WHERE 里不能用聚合函数（还没分组），要用 HAVING
- WHERE 里不能用 SELECT 中定义的别名（SELECT 还没执行）
- ORDER BY 里可以用别名（SELECT 已经执行完了）

## 速记

```sql
SELECT category_id, COUNT(*) AS cnt, ROUND(AVG(price), 2) AS avg_price
FROM dish
WHERE status = 1                 -- 分组前过滤行
GROUP BY category_id
HAVING COUNT(*) >= 4             -- 分组后过滤组
ORDER BY cnt DESC;

CASE WHEN price < 15 THEN '便宜' WHEN price <= 35 THEN '适中' ELSE '贵' END
IFNULL(description, '暂无描述')
DATE_FORMAT(order_time, '%Y-%m-%d %H:%i:%s')
```

## 常见坑

1. `ONLY_FULL_GROUP_BY`：SELECT 的列要么在 GROUP BY 里，要么在聚合函数里（MySQL 8 默认开启）。
2. `COUNT(*)` 统计行数，`COUNT(列)` 不统计 NULL，`COUNT(DISTINCT 列)` 去重计数。
3. `AVG` 结果小数位很多，记得 `ROUND`。
4. 时间范围用“左闭右开”：`order_time >= '2024-05-05' AND order_time < '2024-05-06'`。
