## 连接方式一图看懂

```
INNER JOIN：只要两边都匹配上的        A ∩ B
LEFT JOIN ：A 全部保留，B 匹配不上补 NULL   A
RIGHT JOIN：反过来（很少用，一般把表换个位置用 LEFT JOIN）
```

## 速记

```sql
SELECT d.name AS dish_name, c.name AS category_name
FROM dish d
         LEFT JOIN category c ON d.category_id = c.id   -- 关联条件写 ON
WHERE d.status = 1;                                       -- 过滤条件写 WHERE

-- 子查询
WHERE price > (SELECT AVG(price) FROM dish)                         -- 标量子查询
WHERE id IN (SELECT user_id FROM orders WHERE status = 5)           -- IN 子查询
WHERE NOT EXISTS (SELECT 1 FROM orders o WHERE o.user_id = u.id)    -- 相关子查询
```

## 常见坑

1. 多张表有同名列（id、name、status）时，必须加表别名前缀。
2. `LEFT JOIN` 后又在 `WHERE` 里对右表加条件，会把 NULL 行过滤掉，变成了 INNER JOIN（q12）。
3. 一对多 JOIN 之后行数会“变多”（一个订单有 3 条明细，JOIN 后就是 3 行），统计时注意别重复计算。
4. `NOT IN` 子查询里有 NULL 时结果为空（m05-04 会遇到），优先用 `NOT EXISTS`。
