## 速记

```sql
CREATE DATABASE takeout DEFAULT CHARSET utf8mb4;   -- 建库
DROP TABLE IF EXISTS dish;                          -- 删表（不存在也不报错）

CREATE TABLE dish (
    id          BIGINT         NOT NULL AUTO_INCREMENT COMMENT '主键',
    name        VARCHAR(32)    NOT NULL COMMENT '名称',
    price       DECIMAL(10, 2) NOT NULL COMMENT '价格',
    status      TINYINT        NOT NULL DEFAULT 1 COMMENT '状态',
    create_time DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_name (name)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '菜品';
```

## MySQL 类型 ↔ Java 类型

| MySQL | Java | 用途 |
|---|---|---|
| `BIGINT` | `Long` | 主键、外键 id |
| `INT` | `Integer` | 数量、排序 |
| `TINYINT` | `Integer` | 状态、类型、是否（0/1） |
| `DECIMAL(10,2)` | `BigDecimal` | 金额 |
| `VARCHAR(n)` | `String` | 短文本，n 是字符数 |
| `TEXT` | `String` | 长文本 |
| `DATETIME` | `LocalDateTime` | 日期时间 |
| `DATE` | `LocalDate` | 日期 |

## 常见坑

1. 金额用 `FLOAT/DOUBLE` 会有精度问题，一律 `DECIMAL`。
2. `VARCHAR` 必须指定长度；`CHAR(n)` 是定长，不足会补空格，一般只用于固定长度的值。
3. 字符集用 `utf8mb4`，不要用 `utf8`（MySQL 的 `utf8` 只支持 3 字节，存不了 emoji）。
4. 表名、列名用小写 + 下划线（`create_time`），Java 字段用驼峰（`createTime`）。
5. 表名或列名和关键字冲突时（比如 `order`）用反引号包起来：`` `order` ``，更好的办法是换个名字（`orders`）。
