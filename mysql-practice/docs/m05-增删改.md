## 速记

```sql
INSERT INTO dish (name, category_id, price) VALUES ('小笼包', 3, 18), ('煎饺', 3, 12);
UPDATE dish SET price = price * 1.1, status = 1 WHERE category_id = 1;
DELETE FROM shopping_cart WHERE user_id = 1;

INSERT INTO dish_backup SELECT * FROM dish WHERE status = 0;
DELETE f FROM dish_flavor f JOIN dish d ON d.id = f.dish_id WHERE d.status = 0;
INSERT INTO cart (user_id, dish_id) VALUES (1, 1) ON DUPLICATE KEY UPDATE number = number + 1;
```

## 好习惯

1. **UPDATE / DELETE 先写 WHERE**，并先用 `SELECT ... WHERE 同样的条件` 确认影响范围。
2. 改重要数据前先备份（q07）。
3. 在客户端里手动改数据时，先 `START TRANSACTION;`，确认无误再 `COMMIT;`，改错了 `ROLLBACK;`（m06 会讲）。
