# 常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `连接不上 MySQL ... Communications link failure` | MySQL 没启动，或者端口不对 | 启动 MySQL 服务；检查 db.properties 的 host / port |
| `Access denied for user 'root'@'localhost'` | 密码不对 | 改 db.properties 的 db.password |
| `Public Key Retrieval is not allowed` | MySQL 8 的认证方式需要这个参数 | 测试已经自动加上；客户端里在驱动属性中设 `allowPublicKeyRetrieval=true` |
| `xxx.sql 还没有写 SQL` | 练习文件里 `-- 在下面写你的 SQL：` 下面是空的 | 写上 SQL |
| `You have an error in your SQL syntax ... near 'xxx'` | 语法错误，`near` 后面就是出错的位置 | 检查拼写、逗号、括号、引号；关键字之间要有空格 |
| `Unknown column 'xxx' in 'field list'` | 列名写错，或者多表查询时没加表别名 | 对照 docs/表结构说明.md 检查列名 |
| `Column 'name' in field list is ambiguous` | 多表都有 name 列，MySQL 不知道你要哪个 | 写成 `d.name` / `c.name` |
| `Expression #2 of SELECT list is not in GROUP BY clause ... only_full_group_by` | SELECT 了一个既不在 GROUP BY 里、也不在聚合函数里的列 | 把它加到 GROUP BY，或者放进聚合函数，见 m03-03 讲解 |
| `Invalid use of group function` | 在 WHERE 里用了 COUNT / SUM 等聚合函数 | 改用 HAVING，或者用子查询 |
| `Duplicate entry 'xxx' for key 'uk_name'` | 违反了唯一约束 | 数据重复了，检查数据 |
| `Field 'xxx' doesn't have a default value` | NOT NULL 的列插入时没给值、也没有默认值 | INSERT 时给这个列赋值 |
| `Data too long for column 'xxx'` | 字符串超过了 VARCHAR(n) 的长度 | 缩短数据或加大列长度 |
| `Cannot add or update a child row: a foreign key constraint fails` | 外键指向的记录不存在 | 先插入被引用的数据 |
| `You can't specify target table 'xxx' for update in FROM clause` | UPDATE / DELETE 的子查询里又查了同一张表 | 改成 JOIN 写法，或者把子查询再包一层 `SELECT * FROM (...) t` |
| 测试提示“列名不对” | 列的顺序或别名和题目要求不一致 | 按题目“返回列”的顺序写，用 AS 起别名 |
| 测试提示“这道题要求排序” | 少写或写错了 ORDER BY | 按题目“排序”要求写 ORDER BY |
| 中文显示成问号 | 客户端或控制台编码问题 | 建库时用 utf8mb4；Windows 命令行先执行 `chcp 65001` |
