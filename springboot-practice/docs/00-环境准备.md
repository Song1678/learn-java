# 00 环境准备

## 1. 需要的软件

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 17（或更高） | 和 learn-java 一样 |
| Maven | 3.6+ | IDEA 自带一个，也可以用自己装的 |
| IntelliJ IDEA | 社区版即可 | Lombok 插件新版 IDEA 已经内置 |
| MySQL | 8.x | mysql-practice 用的那个就行；装了 Docker 也可以在本目录执行 `docker compose up -d` |
| 调接口的工具 | Apifox / Postman 任选 | 只调 GET 接口的话浏览器就够了 |

## 2. 打开项目

1. IDEA → File → Open → 选择 **`springboot-practice` 目录**（不是 learn-java 根目录）→ 以 Maven 项目打开
2. 第一次打开会下载依赖（Spring Boot、MyBatis-Plus 等，一百多 MB），右下角有进度条，等它结束
   - 下载很慢的话，可以在 Maven 的 `settings.xml` 里配置阿里云镜像（搜索“Maven 阿里云镜像”）
3. File → Project Structure → Project，SDK 选 17
4. 打开 `db.properties`，改成你的 MySQL 密码

> **Lombok**：本项目的实体类用了 `@Data`，编译时自动生成 getter / setter。
> 如果 IDEA 里 `getName()` 标红但 `mvn test` 能通过，打开 Settings → Build → Compiler → Annotation Processors，勾选 **Enable annotation processing**。

## 3. 启动项目

运行 `src/main/java/com/learn/web/WebPracticeApplication.java` 的 main 方法（或命令行 `mvn spring-boot:run`），看到：

```
Tomcat started on port 8080 (http) with context path '/'
Started WebPracticeApplication in 3.2 seconds
```

就是启动成功了。它是一个一直在运行的 Web 服务器，要停止就点 IDEA 的红色方块。
**改了代码要重启才生效**（点 IDEA 的重新运行按钮）。

启动时会自动执行 `sql/schema.sql` 和 `sql/data.sql`，把 `learn_web` 库重置成示例数据（库不存在会自动创建）。
所以你用接口新增、删除的数据，重启后都会恢复原样 —— 放心随便调。

## 4. 调接口

**GET 请求**：直接在浏览器地址栏输入，例如 http://localhost:8080/w01/greet?name=Tom

**POST / PUT / DELETE**：用 Apifox / Postman：

1. 新建请求，选方法（POST），填地址 `http://localhost:8080/w02/dishes`
2. Body 选 **JSON**（raw / json），填：
   ```json
   {"name": "小笼包", "categoryId": 3, "price": 18.5}
   ```
3. 发送，看返回的 JSON

命令行也可以用 curl：

```bash
curl http://localhost:8080/w02/dishes/1
curl -X POST http://localhost:8080/w02/dishes -H "Content-Type: application/json" -d "{\"name\":\"小笼包\",\"categoryId\":3,\"price\":18.5}"
curl -X DELETE http://localhost:8080/w02/dishes/1,2
```

## 5. 看 MyBatis 执行的 SQL

启动项目后，控制台会打印每一条 SQL 和参数（`application.yml` 里把 `com.learn.web` 的日志级别设成了 debug）：

```
==>  Preparing: SELECT * FROM category WHERE id = ?
==> Parameters: 2(Long)
<==      Total: 1
```

**这是调试 MyBatis 最重要的手段**：结果不对时，先看它实际执行的 SQL 是什么，复制到 DBeaver 里跑一下。

跑测试时默认不打印 SQL（太多了）。想看的话，把 `src/test/resources/application-test.yml` 里的 `info` 改成 `debug`。

## 6. 跑测试

和 learn-java 一样：点测试类 / 测试方法旁边的绿色 ▶，或者命令行 `mvn test -Dtest=W01HelloTest`。

- 第一个测试会慢几秒（在启动 Spring 容器），同一次运行里后面的测试共用这个容器，就快了
- w01 ~ w04 不需要数据库；b01 起的测试需要 MySQL，每个测试方法前会重置 `learn_web_test` 库
- 测试失败时，先看 **我们写的中文提示**，再往下找 **`Caused by:`** —— 最后一个 Caused by 一般就是根本原因
- 测试报错和看不懂的英文异常，去 [常见报错.md](常见报错.md) 里搜一下

## 7. 关于 solutions（参考答案）

- `solutions/java` 和 `solutions/resources` 和练习目录一一对应，答案用 `// @answer ... // @end` 包起来
- `mvn test -Psolutions`：用参考答案跑全部测试，应该全绿
- 想运行参考答案版的项目：`mvn spring-boot:run -Psolutions`
