# 常见报错

先找到**真正的原因**：测试报错往下翻，找最后一个 `Caused by:`；项目启动失败看控制台最后的 `APPLICATION FAILED TO START` 那一段。

## 启动 / 容器

| 报错 | 原因 | 解决 |
|---|---|---|
| `Failed to load ApplicationContext` | 测试启动 Spring 容器失败，所有测试都会红 | 往下翻找 `Caused by`，是下面几种之一 |
| `expected single matching bean but found 2` | 同一个类型有多个 bean | `@Primary` 或 `@Qualifier`（w03） |
| `No qualifying bean of type 'xxx' available` | 容器里没有这个 bean | 类上加 `@Component` / `@Service`；Mapper 接口加 `@Mapper`；类要在 `com.learn.web` 包下 |
| `Error parsing Mapper XML` / `XML fragments parsed from previous mappers does not contain value` | XML 映射文件写错了（标签没闭合、引用的 sql id 不存在等） | 看报错里的文件名和行号 |
| `元素内容必须由格式正确的字符数据或标记组成` | XML 里直接写了 `<` | 写成 `&lt;`，或用 `<![CDATA[ ... ]]>` |
| `Mapped Statements collection already contains value for xxx` | 同一个方法既写了注解 SQL 又写了 XML | 删掉一个 |
| `Port 8080 was already in use` | 项目已经在运行了（可能是另一个窗口） | 停掉之前运行的；或者 application.yml 改 `server.port` |
| `java: 错误: 不支持发行版本 17` | IDEA 用的 JDK 版本低 | Project Structure 和 Settings → Build → Compiler → Java Compiler 都改成 17 |
| `找不到符号 getName()` 但 mvn test 能过 | IDEA 没处理 Lombok | Settings → Build → Compiler → Annotation Processors → 勾选 Enable annotation processing |

## 接口（HTTP）

| 现象 | 原因 | 解决 |
|---|---|---|
| 404 | 没有匹配的接口 | 类上有没有 `@RestController`、路径拼写、`@RequestMapping` 前缀 |
| 405 Method Not Allowed | 请求方式不对 | GET / POST / PUT / DELETE 和注解对上 |
| 415 Unsupported Media Type | 用 `@RequestBody` 接收，但请求不是 JSON | Apifox 里 Body 选 JSON；curl 加 `-H "Content-Type: application/json"` |
| 400 Bad Request | 参数类型转换失败或缺少必填参数 | 日期加 `@DateTimeFormat`；必填参数有没有传；数字参数传了字母 |
| 参数全是 null，但不报错 | JSON 请求体没加 `@RequestBody`；或者 JSON 字段名和 Java 字段名不一致 | 加注解；字段名用驼峰 `categoryId` |
| `JSON parse error` | JSON 格式错误（少了引号、多了逗号） | 检查 JSON |
| 返回的日期是 `2024-04-05T10:10:00` | 没加 `@JsonFormat` | w02 练习 2.8 |
| 测试提示“请求时抛出了异常（没有被处理）” | 异常没有被全局异常处理器接住 | w04 做完前是正常的；做完后检查 `@ExceptionHandler` |

## MyBatis

| 报错 | 原因 | 解决 |
|---|---|---|
| `Invalid bound statement (not found): xxx.selectAll` | 这个方法没有对应的 SQL | 写注解；或者检查 XML 的 namespace（接口全类名）和 id（方法名） |
| `Parameter 'xxx' not found. Available parameters are [arg0, param1 ...]` | `#{xxx}` 找不到参数 | 多个参数加 `@Param("xxx")`；名字要对上；对象参数直接写字段名 |
| `There is no getter for property named 'xxx' in 'class ...'` | `#{xxx}` 或 `<if test="xxx">` 写的字段在对象里不存在 | 用 Java 字段名，不是列名 |
| `You have an error in your SQL syntax ... near 'xxx'` | SQL 语法错 | 打开 SQL 日志看实际执行的 SQL；注解里拼接字符串时注意空格 |
| `Unknown column 'xxx' in 'field list'` | 列名写错；或者 MyBatis-Plus 实体里有非表字段 | 对照表结构；非表字段加 `@TableField(exist = false)`（p01） |
| `Column 'name' in field list is ambiguous` | 多表都有 name 列 | 加表别名 `d.name` |
| 查出来的字段是 null | 列名和字段名对不上 | 起别名 `c.name AS category_name`；确认驼峰映射开着 |
| 一对多只查出一个子元素 / 主对象重复 | resultMap 里少了 `<id>` | b03 |
| `Expected one result (or null) to be returned by selectOne(), but found: 2` | `selectOne` / `.one()` 查出了多条 | 检查条件，或者改用 `selectList` |

## MyBatis-Plus

| 现象 | 原因 | 解决 |
|---|---|---|
| 插入后 id 是 19 位的大数字 | 默认主键策略是雪花算法 | `@TableId(type = IdType.AUTO)`（p01） |
| 分页返回全部数据、total 是 0 | 没注册分页插件 | p03 练习 3.1 |
| createTime / updateTime 没自动填充 | 字段没加 `fill`，或处理器没注册 | p03 练习 3.2、3.3 |
| `updateById` 后某字段没变成 null | `updateById` 跳过 null 字段 | 用 `LambdaUpdateWrapper.set(字段, null)` |
| 删除后数据还在表里 | 加了 `@TableLogic`，这是逻辑删除 | 正常现象 |

## 数据库连接

| 报错 | 原因 | 解决 |
|---|---|---|
| `连接不上 MySQL ... Communications link failure` | MySQL 没启动或端口不对 | 启动 MySQL；检查 `db.properties` |
| `Access denied for user 'root'@'localhost'` | 密码不对 | 改 `db.properties` |
| `Data truncation: Data too long for column` | 字符串超过列长度 | 缩短数据；加 `@Size` 校验 |
| `Duplicate entry 'xxx' for key 'uk_name'` | 违反唯一约束（重名） | Service 里先检查是否已存在，抛 ServiceException |
| 控制台中文乱码（Windows） | 控制台编码 | IDEA：Settings → Editor → File Encodings 全部 UTF-8；Help → Edit Custom VM Options 加 `-Dfile.encoding=UTF-8` |
