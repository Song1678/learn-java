# 阶段三-A 学习计划：每天 5~6 小时，1~2 周

阶段三-A = **MySQL**（[mysql-practice](../../mysql-practice/README.md)）+ **Spring Boot Web + MyBatis / MyBatis-Plus**（本项目）。

- **还没做 mysql-practice**：按下面的完整计划走，第 1~4 天 MySQL，第 5~13 天本项目，第 14 天机动，共 **2 周**。
- **已经做完 mysql-practice**：直接从第 5 天开始，共约 **9~10 天**（1.5 周）。

每天的安排都是“**学习 → 做题 → 调接口 / 复盘**”三段，大致按 2 : 3 : 1 分配时间。
学习资料以本项目的指南为主线，配合视频看：B 站黑马程序员《JavaWeb 开发教程》的 Spring Boot Web / MyBatis / 事务部分，
以及 [MyBatis 中文文档](https://mybatis.org/mybatis-3/zh_CN/index.html)、[MyBatis-Plus 文档](https://baomidou.com/)。

## 每天怎么学（5~6 小时的分配示例）

```
1.5~2 h  学：看指南 + 对应的视频 / 文档，边看边在 IDEA 里敲一遍示例
2.5~3 h  做：做题、跑测试、看报错、改代码（卡住 20 分钟再看答案）
0.5~1 h  复盘：启动项目用 Apifox 调接口；对答案；在 README 进度表里打 ✅；git commit
```

每天结束前 `git commit` 一次，提交信息写当天做了什么（比如 `w02: 完成 2.1~2.5`），养成习惯，公司项目也是这么干的。

## 阶段三-A 完成后的自查清单

能不看资料回答 / 写出来，就可以进入阶段三-B：

**MySQL**
- [ ] 写出“按日期统计营业额（没有数据的日期补 0）”和“销量 Top10”的 SQL
- [ ] INNER JOIN / LEFT JOIN、WHERE / HAVING 的区别；什么情况下索引会失效

**Spring Boot Web**
- [ ] 一个 HTTP 请求从浏览器到 Controller 方法，中间 Spring 做了哪些事（找方法、转换参数、调用、转 JSON）
- [ ] @RequestParam、@PathVariable、@RequestBody 分别什么时候用；不加注解的对象参数是怎么接收的
- [ ] IoC / DI 是什么；@Component 和 @Bean 的区别；同一个接口有两个实现时怎么注入
- [ ] 全局异常处理器怎么工作；为什么 Controller 里不需要 try-catch
- [ ] @Validated 分组校验：为什么 RuoYi 的 Bo 里每个注解都写了 groups

**MyBatis / MyBatis-Plus**
- [ ] #{} 和 ${} 的区别；ORDER BY 的列名为什么只能用 ${}，怎么防注入
- [ ] 动态 SQL 的 &lt;where&gt; 和 &lt;set&gt; 帮你处理了什么
- [ ] 一对多查询为什么要用 resultMap + &lt;collection&gt;，&lt;id&gt; 起什么作用
- [ ] @Transactional 什么时候回滚；受检异常、吞掉异常、自调用三种失效情况
- [ ] BaseMapper 和 ch09 的 InMemoryMapper 有什么对应关系；updateById 为什么不会把 null 字段写进数据库
- [ ] LambdaQueryWrapper 带 boolean 参数的写法是干什么的；and(w -> ...) 为什么必要
- [ ] 分页插件做了什么；自动填充、逻辑删除是怎么实现的
- [ ] 什么是 N+1 问题，怎么避免

**综合**
- [ ] 能画出 x01 的分层结构图：Controller → IService → ServiceImpl → Mapper → DB，并说出 Bo / Entity / Vo 各自的作用
