# p03 分页插件、自动填充、逻辑删除

> 先看：[MyBatis-Plus 文档](https://baomidou.com/) “插件 → 分页插件”“自动填充字段”“逻辑删除”
> 参考：RuoYi-Vue-Plus `ruoyi-common-mybatis` 模块的 `MybatisPlusConfig`、`InjectionMetaObjectHandler`、`PageQuery`、`TableDataInfo`
> 练习：`src/main/java/com/learn/web/p03_page/`　判题：`mvn test -Dtest=P03PageTest`

⚠️ 本章的分页插件和自动填充是**全局配置**，x01 综合项目也依赖它们，所以 x01 之前一定要先做完本章。

## 分页

```java
@Bean
public MybatisPlusInterceptor mybatisPlusInterceptor() {
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
    return interceptor;
}

// 使用
Page<Dish> page = dishMapper.selectPage(new Page<>(pageNum, pageSize), wrapper);
page.getRecords();   // 当前页数据
page.getTotal();     // 总条数
```

执行 `selectPage` 时插件做了两件事（打开 SQL 日志能看到）：

```
SELECT COUNT(*) AS total FROM dish WHERE category_id = ?             ← 先查总数
SELECT id,name,... FROM dish WHERE category_id = ? ORDER BY id ASC LIMIT ?,?   ← 再加 LIMIT
```

RuoYi-Vue-Plus 的分页三件套（本项目 `common` 包里有同款）：

```java
public TableDataInfo<DishVo> queryPageList(DishBo bo, PageQuery pageQuery) {
    LambdaQueryWrapper<Dish> lqw = buildQueryWrapper(bo);
    Page<DishVo> result = baseMapper.selectVoPage(pageQuery.build(), lqw);   // 本项目用 selectPage
    return TableDataInfo.build(result);
}
```

## 自动填充

```java
@TableField(fill = FieldFill.INSERT)           private LocalDateTime createTime;
@TableField(fill = FieldFill.INSERT_UPDATE)    private LocalDateTime updateTime;

@Component
public class MyMetaObjectHandler implements MetaObjectHandler {
    public void insertFill(MetaObject mo) { this.strictInsertFill(mo, "createTime", LocalDateTime.class, LocalDateTime.now()); ... }
    public void updateFill(MetaObject mo) { this.strictUpdateFill(mo, "updateTime", LocalDateTime.class, LocalDateTime.now()); }
}
```

RuoYi-Vue-Plus 的实体都继承 `BaseEntity`（createBy、createTime、updateBy、updateTime），`createBy` 填的是当前登录用户 —— 阶段三-B 学了登录之后就懂了。

## 逻辑删除

```java
@TableLogic
private Integer delFlag;    // 0 正常 1 已删除（MP 的默认值，可以在 yml 里改）
```

加上之后，这个实体的 `deleteById` 变成 `UPDATE ... SET del_flag = 1`，所有查询自动加 `WHERE del_flag = 0`。
注意：**只对 MyBatis-Plus 生成的 SQL 生效**，你在 XML 里手写的 SQL 要自己加 `del_flag = 0` 条件。

## 常见坑

1. 分页返回了全部数据、total 是 0 → 没注册分页插件（3.1）。
2. MyBatis-Plus 3.5.9 以后分页插件在单独的 `mybatis-plus-jsqlparser` 依赖里（本项目 pom 已经加了），网上老教程里没有这一步。
3. 自动填充没生效 → 字段上没加 `fill`，或者处理器类没加 `@Component`，或者字段名字符串写错了（`"createTime"` 是 Java 字段名，不是列名）。
4. `strictUpdateFill` 是“字段为 null 才填”：先 selectById 出来的对象 updateTime 有旧值，再 updateById 时不会被刷新。
