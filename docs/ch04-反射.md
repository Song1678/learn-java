# ch04 反射

> 对应廖雪峰：反射（Class 类、访问字段、调用方法、调用构造方法、获取继承关系）
> 练习目录：`src/main/java/com/learn/ch04_reflection/`
> 运行：`mvn test -Dtest='com.learn.ch04_reflection.**'`

## 为什么要学反射

业务代码里你几乎不会直接写反射，但**所有框架都建立在反射之上**：
Spring 创建对象、注入依赖；MyBatis 把查询结果填进实体；Jackson 把对象转 JSON；BeanUtil 复制属性……
理解反射，框架就不再是“黑魔法”。

## 知识点速记

```java
Class<?> clazz = user.getClass();            // 或 SysUser.class
clazz.getDeclaredFields();                   // 本类声明的所有字段（含 private，不含父类）
clazz.getFields();                           // 所有 public 字段（含父类）
clazz.getSuperclass();                       // 父类

Field f = clazz.getDeclaredField("password");
f.setAccessible(true);                       // 允许访问 private
Object v = f.get(user);
f.set(user, "newPwd");

Method m = clazz.getDeclaredMethod("add", int.class, int.class);
Object r = m.invoke(user, 1, 2);
```

## 常见坑

1. `getDeclaredFields` 不包含父类字段，要自己循环 `getSuperclass()`。
2. 反射方法抛的都是受检异常（`IllegalAccessException` 等），练习里统一包成 `RuntimeException`。
3. `int` 和 `Integer` 在反射里是不同的类型：`int.class != Integer.class`。
4. `Method.invoke` 里方法抛异常时，你拿到的是 `InvocationTargetException`，真正的异常在 `getCause()`。
