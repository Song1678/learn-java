## 知识点速记

```java
// 泛型类：T 在 new 的时候确定
public class R<T> { private T data; }
R<User> r = R.ok(user);

// 静态方法不能用类上的 T，要自己声明
public static <T> R<T> ok(T data) { ... }

// PECS：Producer Extends, Consumer Super
double sum(List<? extends Number> list)        // 只读：可以传 List<Integer>、List<Double>
void fill(List<? super Integer> list)          // 只写：可以传 List<Integer>、List<Number>、List<Object>
```

> TypeScript 对照：`function ok<T>(data: T): R<T>`、`<T extends Comparable>` ≈ `<T extends { compareTo(...): number }>`

## 常见坑

1. `List<Integer>` **不是** `List<Number>` 的子类型（虽然 Integer 是 Number 的子类）。需要通配符 `List<? extends Number>`。
2. 类型擦除：运行时 `List<String>` 和 `List<Integer>` 是同一个类，所以不能 `new T()`、不能 `instanceof List<String>`。
3. 泛型参数只能是引用类型：`List<int>` ❌，`List<Integer>` ✅。
4. 分页计算 `(pageNum - 1) * pageSize` 可能 int 溢出，测试里专门有一个用例。
