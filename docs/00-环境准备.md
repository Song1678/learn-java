# 00 环境准备

## 1. 安装 JDK 17

RuoYi-Vue-Plus 5.x 要求 JDK 17+，所以统一用 17。

- 推荐下载 [Eclipse Temurin 17](https://adoptium.net/zh-CN/temurin/releases/?version=17)（或者在 IDEA 里一键下载，见下文）
- 安装后在终端检查：

```bash
java -version    # 应该显示 17.x
javac -version
```

> 和 Node.js 类比：JDK ≈ Node 运行时 + 编译器。`java` ≈ `node`，`javac` 是编译器（JS 不需要编译这一步）。

## 2. 安装 Maven

Maven ≈ Java 世界的 npm：`pom.xml` ≈ `package.json`，依赖下载到 `~/.m2/repository` ≈ `node_modules`（但是全局共享）。

- IDEA 自带 Maven，**只用 IDEA 的话可以不单独装**。
- 想在命令行用：从 [maven.apache.org](https://maven.apache.org/download.cgi) 下载解压，把 `bin` 加到 PATH，`mvn -v` 检查。
- 国内下载依赖慢的话，在 `~/.m2/settings.xml` 配置阿里云镜像：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

| npm | Maven |
|---|---|
| `npm install` | `mvn compile`（自动下载依赖） |
| `npm test` | `mvn test` |
| `npm run build` | `mvn package` |
| `package.json` 的 dependencies | `pom.xml` 的 `<dependencies>` |
| `npm run xxx` 跑脚本 | `mvn exec:java -Dexec.mainClass=...` 跑 main 方法 |

## 3. 安装 IntelliJ IDEA

- 社区版（Community）免费，够用；公司如果有旗舰版（Ultimate）更好，Spring 支持更完整。
- 打开项目：`File → Open` 选择本项目根目录（有 `pom.xml` 的那层）。
- 设置 JDK：`File → Project Structure → Project → SDK` 选 17（没有的话点 `Download JDK` 直接下）。
- 右侧会出现 Maven 面板，第一次打开会自动下载依赖（JUnit）。

### 常用操作

| 操作 | 快捷键（Windows / Mac） |
|---|---|
| 运行当前测试/main | 点代码左边的绿色 ▶，或 `Ctrl+Shift+F10` / `Ctrl+Shift+R` |
| 跳到定义 | `Ctrl+B` / `Cmd+B` |
| 在测试和源码之间跳转 | `Ctrl+Shift+T` / `Cmd+Shift+T` |
| 自动补全 import | `Alt+Enter` / `Option+Enter` |
| 格式化代码 | `Ctrl+Alt+L` / `Cmd+Option+L` |
| 生成 getter/setter/构造方法/equals | `Alt+Insert` / `Cmd+N` |
| 全局搜索 | 双击 `Shift` |
| 打断点调试 | 点行号右侧出现红点，然后用 🐞 Debug 运行 |

> **一定要学会 Debug**：打断点 → Debug 运行 → F8 单步 / F7 进入方法，看变量值。
> 这比到处 `System.out.println` 高效得多，以后排查 RuoYi 里的问题全靠它。

## 4. 做题流程

1. 打开练习文件（例如 `src/main/java/com/learn/ch01_basics/Ex01_Types.java`）
2. 读类注释和方法注释，里面有需求和示例
3. 删掉 `throw new UnsupportedOperationException("TODO: 还没实现");`，写你的实现
4. `Ctrl+Shift+T` 跳到对应测试类，点 ▶ 运行
5. 看测试结果：
   - 绿色 ✅：通过
   - `UnsupportedOperationException: TODO`：这个方法还没写
   - `expected: <xx> but was: <yy>`：结果不对，expected 是期望值，but was 是你的返回值
   - `Expected IllegalArgumentException to be thrown, but nothing was thrown`：该抛异常的地方没有抛

## 5. 常见问题

**Q：控制台中文乱码？**
IDEA：`Settings → Editor → File Encodings` 全部设成 UTF-8；还不行就在 `Help → Edit Custom VM Options` 加一行 `-Dfile.encoding=UTF-8`，重启 IDEA。
命令行（Windows）：先执行 `chcp 65001` 切换到 UTF-8。

**Q：`mvn test` 一片红？**
正常，所有练习一开始都没实现。用 `-Dtest=` 只跑你正在做的那一章。

**Q：我改了 solutions 里的文件，会影响我的练习吗？**
不会。默认编译 `src/main/java`；只有加 `-Psolutions` 才编译 `solutions/`，而且输出到单独的 `target-solutions/` 目录。

**Q：IDEA 里能直接跑 solutions 吗？**
可以：右侧 Maven 面板 → Profiles 勾选 `solutions` → 点刷新按钮。跑完记得取消勾选再刷新，换回你自己的练习。
