# ch05 注解

> 对应廖雪峰：注解（使用注解、定义注解、处理注解）
> 练习目录：`src/main/java/com/learn/ch05_annotation/`
> 运行：`mvn test -Dtest='com.learn.ch05_annotation.**'`

## 本章目标

注解本身什么都不做，它只是“贴在代码上的标签”。**真正干活的是读取注解的代码**（通常用反射）。
做完本章，你会明白 Spring Boot 里满天飞的 `@NotBlank`、`@Excel`、`@Log` 是怎么生效的。

## 知识点速记

```java
@Retention(RetentionPolicy.RUNTIME)   // SOURCE: 编译后丢弃；CLASS: 存在 class 文件但运行时读不到；RUNTIME: 运行时可以反射读取
@Target(ElementType.FIELD)            // 能贴在哪：TYPE 类、FIELD 字段、METHOD 方法、PARAMETER 参数
public @interface Range {
    long min() default Long.MIN_VALUE; // 注解的“参数”写成方法的样子
    long max() default Long.MAX_VALUE;
    String message() default "超出范围";
}

// 读取
Range r = field.getAnnotation(Range.class);   // 没有则为 null
if (r != null) { r.min(); r.max(); }

// Java 16+ 模式匹配，判断类型的同时完成强转
if (value instanceof String s && s.length() > 10) { ... }
```
