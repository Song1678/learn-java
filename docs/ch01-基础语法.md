## 知识点速记

```java
int a = 7 / 2;          // 3，整数除法
double b = 7 / 2.0;     // 3.5
double c = (double) 7 / 2; // 3.5，先强转再除
long big = (long) Integer.MAX_VALUE + 1; // 先转 long 再加，不会溢出

char ch = '7';
int digit = ch - '0';   // 7，char 本质是数字

String s = "abc";
s.equals("abc");        // ✅ 比较内容
s == "abc";             // ❌ 比较的是引用，不要这样写

// switch 表达式（Java 14+），没有 break 穿透问题
String level = switch (score / 10) {
    case 10, 9 -> "A";
    case 8 -> "B";
    default -> "E";
};
```

## 常见坑

1. `percent(1, 3)` 得到 0？—— `1 / 3` 是整数除法，先转 `double`。
2. 平均值溢出？—— 两个 `Integer.MAX_VALUE` 相加会变成负数，求和用 `long`。
3. `String` 是不可变的，`s.toUpperCase()` 不会改变 `s`，要接住返回值。
4. 循环里大量拼接字符串用 `StringBuilder`，不要用 `+=`。
5. 数组越界会抛 `ArrayIndexOutOfBoundsException`（JS 里只会得到 `undefined`）。
