## Stream 速记

```java
orders.stream()
      .filter(o -> o.status() == COMPLETED)     // 过滤
      .map(Order::amount)                       // 转换
      .reduce(BigDecimal.ZERO, BigDecimal::add);// 归约

// 分组计数：Map<Status, Long>
orders.stream().collect(Collectors.groupingBy(Order::status, Collectors.counting()));

// 一对多摊平：订单流 → 明细流
orders.stream().flatMap(o -> o.items().stream())

// Optional：可能没有值
orders.stream().max(Comparator.comparing(Order::amount))   // Optional<Order>
      .map(Order::id)
      .orElse(-1L);
```

## 迷你 IoC 容器：你在模拟什么

```java
MiniContainer c = new MiniContainer(DishController.class, DishService.class, DishMapperImpl.class);
DishController controller = c.getBean(DishController.class);
```

这两行等价于 Spring Boot 启动时做的事：
1. **扫描**带 `@Component`（`@Service`、`@RestController`、`@Mapper` 本质都是它）的类
2. 用反射**创建对象**（只创建一次 → 单例）
3. 找到带 `@Autowired` 的字段，从容器里**按类型**找到对象**注入**进去
4. 按接口类型能拿到实现类（`getBean(DishMapper.class)` 得到 `DishMapperImpl`）

做完这道题，再看 Spring 的 `@Autowired private DishService dishService;` 就不会觉得神奇了。

进阶：A 依赖 B，B 又依赖 A —— Spring 用“三级缓存”解决循环依赖，你只需要“先放进缓存再注入”就够了。

## 常见坑

1. Stream 只能消费一次，用完再用会抛 `IllegalStateException`。
2. `toList()`（Java 16+）返回不可变列表；需要可变列表用 `collect(Collectors.toList())` 或 `new ArrayList<>(...)`。
3. Lambda 里不能修改外部的局部变量（必须是 effectively final）。
4. `LocalDateTime` 是不可变的：`time.plusMinutes(30)` 不会改变 `time`，要接住返回值。
5. 格式字符串大小写敏感：`yyyy-MM-dd HH:mm:ss`（`MM` 月、`mm` 分；`HH` 24 小时制、`hh` 12 小时制）。
