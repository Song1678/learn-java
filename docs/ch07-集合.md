## 选哪个集合？

| 需求 | 用 |
|---|---|
| 有序列表，按下标访问 | `ArrayList` |
| 去重，不关心顺序 | `HashSet` |
| 去重，保持插入顺序 | `LinkedHashSet` |
| 去重并排序 | `TreeSet` |
| key-value，不关心顺序 | `HashMap` |
| key-value，保持插入顺序 | `LinkedHashMap` |
| key-value，按 key 排序 | `TreeMap` |
| 栈 / 队列 | `ArrayDeque`（`push/pop` 或 `offer/poll`） |
| 按优先级出队 | `PriorityQueue` |

## equals 和 hashCode 的规矩

1. `a.equals(b)` 为 true，则 `a.hashCode() == b.hashCode()` 必须为 true。
2. 重写了 `equals` 就**必须**重写 `hashCode`，否则 `HashSet`/`HashMap` 会出错。
3. IDEA 可以自动生成（`Alt+Insert → equals() and hashCode()`），但本题的 BigDecimal 需要你手动处理。

## 常见坑

1. 在 for-each 里 `list.remove(x)` → `ConcurrentModificationException`。用 `iterator.remove()` 或 `removeIf`。
2. `List.of(...)`、`Map.of(...)` 创建的是**不可变**集合，调用 `add` 会抛 `UnsupportedOperationException`。
3. `HashMap` 遍历顺序不确定，需要顺序就用 `LinkedHashMap` 或 `TreeMap`。
