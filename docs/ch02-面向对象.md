## 知识点速记

```java
// 子类构造方法第一行必须调用父类构造方法
public Circle(double radius) {
    super("圆形");
    this.radius = radius;
}

// 父类引用指向子类对象：运行时调用的是子类的方法（多态）
Shape s = new Circle(1);
s.area();

// BigDecimal：钱的计算
BigDecimal a = new BigDecimal("0.1");      // ✅ 用字符串构造
BigDecimal b = new BigDecimal(0.1);         // ❌ 会得到 0.1000000000000000055511151231257827...
a.add(b); a.subtract(b); a.multiply(b);     // 不可变，返回新对象
a.setScale(2, RoundingMode.HALF_UP);        // 保留两位，四舍五入
a.compareTo(b) > 0;                         // 比较大小用 compareTo，不要用 equals

// record：不可变数据类
public record CartItem(String name, BigDecimal price, int quantity) {
    public CartItem {               // 紧凑构造方法，做校验
        if (quantity < 1) throw new IllegalArgumentException();
    }
}
item.name();                        // 注意 getter 没有 get 前缀
```

## 常见坑

1. `new BigDecimal("1.0").equals(new BigDecimal("1.00"))` 是 `false`！比较数值请用 `compareTo`。
2. `static` 字段属于类，所有对象共享；不要在 static 方法里访问实例字段。
3. 子类构造方法没写 `super(...)` 时，编译器会自动插入 `super()`；如果父类没有无参构造方法，就会编译报错。
4. `protected` 字段子类能访问，同一个包里的类也能访问。

## 和后面的联系

- `PayStrategy` 是“策略模式”。Spring 里你会写 `@Autowired private PayStrategy payStrategy;`，具体注入哪个实现由配置决定。
- `OrderStatus` 和苍穹外卖里订单状态码完全一致，第 9 章会直接用到。
- 企业项目的实体类（Entity）就是 JavaBean：private 字段 + getter/setter，通常用 Lombok 的 `@Data` 自动生成。
