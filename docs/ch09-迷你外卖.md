# ch09 综合项目：迷你外卖（内存版）

> 练习目录：`src/main/java/com/learn/ch09_takeout/`
> 运行测试：`mvn test -Dtest='com.learn.ch09_takeout.**'`
> 运行演示：`mvn -q compile exec:java -Dexec.mainClass=com.learn.ch09_takeout.TakeoutApp`

## 目标

在**不引入任何框架**的前提下，按企业项目的分层结构，实现苍穹外卖最核心的一条业务链：

```
管理端：分类管理 → 菜品管理（新增 / 起售停售 / 批量删除）
用户端：浏览菜品 → 加购物车 → 下单 → 支付
商家端：接单 → 派送 → 完成；超时未支付自动取消
数据统计：营业额统计、销量 Top N
```

前 8 章学的东西会全部用上：BigDecimal、枚举、record、自定义异常、泛型 Mapper、集合、Stream、时间 API。
做完以后换成 Spring Boot + MyBatis-Plus + MySQL，主要的变化只是“把 InMemoryMapper 换成数据库”和“用注解代替手动组装”。

## 设计要点（做题前读一遍）

- **校验放在 Service**，失败直接 `throw new ServiceException("...")`，Controller 不写 try/catch。
- **批量删除先全部校验再删**：要么全删，要么一个都不删（真实项目里用 `@Transactional` 事务保证）。
- **支付别人的订单要报“订单不存在”**，而不是“这不是你的订单” —— 不泄露信息。
- **`OrderService` 通过 `Supplier<LocalDateTime> now` 获取当前时间**，测试时可以“拨动时钟”验证 15 分钟超时逻辑。这种“把不确定的东西作为依赖注入”的写法，是让代码可测试的关键。
- 新菜品默认**停售**，起售后用户端才能看到。
